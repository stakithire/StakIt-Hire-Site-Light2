# StakIt Hire - Project Overview

## 1. Business Identity
**Name:** StakIt Hire  
**Tagline:** "Boxes that don’t quit — Pack. Stack. Move."  
**Core Mission:** To revolutionize the moving process by replacing cardboard chaos with eco-friendly, durable, and stackable rental crates.  
**Service Area:** Greater Penrith Area (NSW, Australia).

---

## 2. Design System
- **Primary Purple:** HSL 260 80% 55%
- **Accent Green:** HSL 142 60% 45%
- **Background Gray:** HSL 210 33% 96%
- **Border Radius:** 0.75rem (12px)

---

## 3. Workflow
1. **Browse:** User views packages on the website.
2. **Contact:** User clicks "Book via Facebook" to open Messenger.
3. **Coordinate:** Logistics and dates are finalized via chat.
4. **Delivery:** Equipment delivered and collected as scheduled.
